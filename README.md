# Enquête Citoyenne CI

Plateforme d'enquête citoyenne pour recenser, mesurer et analyser les problèmes réels de la population ivoirienne, afin d'identifier des opportunités de solutions numériques.

## 🚀 Fonctionnalités
*   Formulaire d'enquête dynamique (villes, questions, options).
*   Enregistrement des réponses dans une base de données sécurisée.
*   Espace administrateur avec authentification (login/mot de passe).
*   Tableau de bord pour visualiser les résultats.

## 🛠️ Technologies utilisées
*   **Backend :** Python (Flask)
*   **Base de données :** SQLite
*   **Frontend :** HTML, CSS, JavaScript

## 💻 Installation en local
1. Cloner le projet :
   `git clone https://github.com/KAMS-78/enquete-citoyenne-ci.git`
2. Créer un environnement virtuel :
   `python -m venv venv`
3. Activer l'environnement :
   `venv\Scripts\activate` (Windows)
4. Installer les dépendances :
   `pip install -r requirements.txt`
5. Lancer l'application :
   `python app.py`
